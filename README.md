## 🔗 Some of my projects

### 🖥️ Linux desktop & window management
- 🪟 [**skarwm**](https://github.com/nerdyslacker/skarwm) - keyboard-driven X11 window manager with flexible layouts and IPC.
- 🌸 [**anush**](https://github.com/nerdyslacker/anush) - configurable Linux desktop shell with panels, launchers, notifications, and desktop integrations.

### ⌨️ Terminals & TUI
- 💻 [**nare**](https://github.com/nerdyslacker/nare) - terminal emulator with tabs, panes, quake mode, and a configurable status bar.

### 🛠️ Linux utilities & productivity
- 📋 [**minni**](https://github.com/nerdyslacker/minni) - standalone clipboard history manager for Linux.
- ⚙️ [**lazysvctl**](https://github.com/lazylinuxos/lazysvctl) - runit service management utility.

### 🌐 Networking & communication
- 🔐 [**cattail**](https://github.com/nerdyslacker/cattail) - unofficial Tailscale / Headscale client.
- 👋 [**barev-odin**](https://github.com/nerdyslacker/barev-odin) - Odin implementation of the Barev protocol.
- 💬 [**parior-messenger**](https://github.com/nerdyslacker/parior-messenger) - messaging application based on barev-odin.

### 📦 Linux distributions & packaging
- 🦥 [**LazyLinux**](https://github.com/lazylinuxos/lazylinux-mklive) - custom Linux distribution and live image tooling.
- 📦 [**lazy-repo**](https://github.com/lazylinuxos/lazy-repo) - package repository for LazyLinux.
- 🐉 [**sonicde-void**](https://github.com/sonicde-void/sonicde-void) - SonicDE package repository for Void Linux.
- ⚫ [**blackhole-vl**](https://github.com/Event-Horizon-VL/blackhole-vl) - third-party Void Linux repository. (contributor)
